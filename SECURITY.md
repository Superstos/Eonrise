# Security policy

Eonrise is experimental software and I maintain it solo. It is provided without warranty, and I make no promise about when or whether a vulnerability gets fixed.

## Reporting

Do not publicly disclose sensitive vulnerabilities. Use GitHub private vulnerability reporting for the `Superstos/Eonrise` repository. If private reporting is unavailable, open a public issue without exploit details and ask the maintainer for a safer reporting channel.

Please include:

- affected version or commit
- reproduction steps
- impact
- any relevant logs with secrets redacted

## Supported versions

Only the latest `0.9.x` alpha is supported for security review. Older experimental versions may not receive fixes.
